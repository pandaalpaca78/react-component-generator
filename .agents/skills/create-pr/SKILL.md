# PR 생성

PR 작성·생성 작업은 subagent가 실행한다. 메인 에이전트는 직접 실행하지 말고 subagent 하나에 위임한다. 사용자 요청, 저장소와 이 `SKILL.md`의 절대 경로, 지정된 base·head, PR 언어, 작성만 할지 실제 생성할지를 전달한다. 위임은 사용자가 허용한 범위를 확장하지 않는다.

이미 subagent라면 추가 위임 없이 직접 수행한다. 메인 에이전트는 같은 PR을 동시에 생성하지 않으며, 반환된 제목·본문 또는 PR URL과 검증 결과를 사용자에게 전달한다. Subagent 도구를 사용할 수 없으면 실행하지 말고 제약을 알린다.

PR 제목·본문을 작성하거나 실제 PR을 생성할 때 아래 기준으로 참조 파일 하나만 읽고 따른다. 스킬 설명이나 사용법만 묻는 경우에는 참조를 로드하지 않는다.

- 사용자가 한국어(KR)를 지정하면 [references/pr-template-kr.md](references/pr-template-kr.md)를 읽는다.
- 사용자가 영어(EN)를 지정하면 [references/pr-template-en.md](references/pr-template-en.md)를 읽는다.
- 언어 지정이 없으면 저장소의 PR 언어 규칙을 우선하고, 규칙이 없으면 사용자 요청의 언어를 따른다. 한국어·영어 어느 쪽인지 판단할 수 없으면 한국어를 기본으로 사용한다.
- 두 언어를 모두 요청한 경우에만 두 파일을 읽는다. 두 언어 요청만으로 PR을 두 개 생성하지 않는다.
